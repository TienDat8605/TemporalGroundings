\section{Introduction}
\label{sec:intro}

Temporal video understanding is a core pillar of modern multimodal artificial intelligence, empowering intelligent agents to search, reason over, and index dense visual streams using natural language queries~\cite{gao2017tall,anne2017localizing}. Among various temporal localization tasks, \textbf{Video Temporal Grounding (VTG)} requires retrieving precise start and end timestamps corresponding to a given textual description~\cite{lei2021qvhighlights,lei2021momentdetr}. While traditional VTG benchmarks predominantly focus on the single-instance paradigm where each query corresponds to exactly one isolated moment, real-world untrimmed videos frequently exhibit recurring events. In domains such as surveillance, sports analytics, and life-logging, an action described by an open-vocabulary query (e.g., \emph{"the athlete drinks water"} or \emph{"person opens the refrigerator"}) often repeats multiple times across non-contiguous intervals.

To formalize this challenging capability gap, recent work established \textbf{One-to-Many Video Temporal Grounding (OMTG)}~\cite{omtg2026}. Unlike traditional single-span retrieval, OMTG introduces a coupled dual objective: (1) \emph{cardinality perception} (accurately determining the total number of event occurrences $K \ge 1$), and (2) \emph{boundary localization} (predicting precise temporal timestamps for every individual event). Strikingly, current state-of-the-art Multimodal Large Language Models (MLLMs), including Gemini-1.5-Pro, Video-LLaVA~\cite{lin2023videollava}, and TimeLens-8B~\cite{timelens2024}, experience catastrophic failure when evaluated on OMTG, collapsing to $\mathbf{0.00\%}$ Count Accuracy (C-Acc) and $\mathbf{0.00\%}$ Effective Temporal F1 (EtF1) in official benchmark evaluations~\cite{omtg2026}.

In this paper, we investigate the underlying causes of MLLM cardinality collapse on OMTG and discover that baseline failure stems from two distinct, orthogonal factors:
\begin{enumerate}
    \item \textbf{Conversational Prompt Format Misalignment}: Default benchmark prompts embed formatting instructions within unstructured natural language dialogue, inducing autoregressive generation confusion where instruction-tuned decoders output single timestamps or conversational fragments rather than structured multi-span lists.
    \item \textbf{Background Distractor Pollution in Long Videos}: When fed unpruned untrimmed videos ($100\text{s}-500\text{s}$ in duration), 8B Vision Transformers suffer from visual token dilution across thousands of irrelevant background frames. These empty background intervals act as visual distractors, triggering phantom false-positive hallucinations and crippling event counting accuracy.
\end{enumerate}

To overcome both bottlenecks without parameter fine-tuning, we propose \textbf{Adaptive Scout-Guided Dense Evidence (Adaptive SGDE)}, a completely training-free, zero-shot framework for long-form multi-event temporal grounding. As illustrated in Fig.~\ref{fig:pipeline_intro}, Adaptive SGDE decouples long-video grounding into a hierarchical coarse-to-fine architecture:
\begin{itemize}
    \item \textbf{Stage 1: Coarse Multimodal Scouting}: A frozen 1.04B vision-language embedding scout rapidly scans the untrimmed video at 1.0~FPS, producing a continuous cross-modal similarity timeline normalized by video-level $Z$-scores to neutralize domain baseline shifts.
    \item \textbf{Stage 2: Hysteresis Energy Mining}: A dual-threshold hysteresis search ($\tau_{\text{high}}=0.80, \tau_{\text{low}}=0.25$) combined with a dimensionally consistent normalized excess semantic energy density integral $\bar{J}(a,b)$ extracts candidate action intervals while suppressing transient noise.
    \item \textbf{Stage 3: Sub-Linear Duration-Adaptive Windowing}: Sub-linear context margins ($\Delta(T) \propto \ln T$) and clustering gaps ($G(T) \propto \sqrt{T}$) dynamically cluster candidates across diverse video scales ($12\text{s}-500\text{s}$), unified by a $70\%$ soft continuity merge rule that prevents prompt fragmentation.
    \item \textbf{Stage 4: Focused Dense Grounding}: The primary 8B grounder (TimeLens-8B~\cite{timelens2024}) ingests only the focused candidate corridor under a structured, schema-delimited multi-span JSON prompt, concentrating frame allocation where target actions actually occur.
\end{itemize}

Extensive evaluations on the full 100\% OMTG benchmark ($N=320$) demonstrate that Adaptive SGDE substantially improves training-free grounding, boosting Count Accuracy from $0.00\% \rightarrow \mathbf{33.12\%}$ ($+13.43\%$ over prompt-only baselines) and Effective Temporal F1 to $\mathbf{19.86\%}$ (+19.86 points over official paper baselines). Crucially, by discarding $50\%-85\%$ of irrelevant background intervals, Adaptive SGDE slashes primary 8B Vision Transformer frame evaluations by $\mathbf{60.3\%}$, achieving a true net $\mathbf{-54.0\%}$ end-to-end inference compute reduction.
