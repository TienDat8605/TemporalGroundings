\section{Methodology: Adaptive SGDE}
\label{sec:method}

\subsection{Problem Formulation and Overview}
\label{sec:overview}

Given an untrimmed video $\mathcal{V} = \{f_t\}_{t=1}^{T}$ of duration $T$ seconds and a natural language query $\mathcal{Q}$, One-to-Many Video Temporal Grounding (OMTG)~\cite{omtg2026} requires localizing all $K \ge 1$ disjoint action intervals:
\begin{equation}
    \mathcal{Y}^* = \big\{ [s_k^*, e_k^*] \big\}_{k=1}^{K}, \quad \text{subject to } 0 \le s_1^* < e_1^* < s_2^* < \dots < e_K^* \le T,
    \label{eq:omtg_formulation}
\end{equation}
where each temporal segment $[s_k^*, e_k^*]$ semantically satisfies $\mathcal{Q}$. OMTG requires predicting the total event count $K$ as well as start and end timestamps $[s_k, e_k]$ for each retrieved moment. Standard Multimodal Large Language Models (MLLMs) perform poorly on OMTG due to background frames in long videos and prompt format misalignment.

To address these challenges without fine-tuning, we propose Adaptive Scout-Guided Dense Evidence (Adaptive SGDE). As illustrated in Fig.~\ref{fig:pipeline}, Adaptive SGDE uses a four-stage coarse-to-fine pipeline: (1) 1.0~FPS timeline scouting ($\S$\ref{sec:stage1}), (2) proposal extraction and scoring ($\S$\ref{sec:stage2}), (3) duration-adaptive window planning ($\S$\ref{sec:stage3}), and (4) budgeted dense decoding with structured multi-span output ($\S$\ref{sec:stage4}).

\subsection{Stage 1: Coarse-Grained Temporal Timeline Scouting}
\label{sec:stage1}

\paragraph{Lightweight Multimodal Scouting.} Feeding unpruned raw video into an 8B Vision Transformer requires evaluating large numbers of irrelevant background frames. We instead deploy a lightweight, frozen 1.04B scout $\mathcal{M}_{\text{scout}}$ (Llama-Nemotron-Embed-VL-1B) at a uniform coarse rate of 1.0~FPS. For each timestamp $t \in \{1, \dots, T\}$, we extract frame embedding $\mathbf{v}(t) = \mathcal{M}_{\text{scout}}(f_t)$ and query embedding $\mathbf{q} = \mathcal{M}_{\text{scout}}(\mathcal{Q})$, computing continuous cross-modal cosine similarity:
\begin{equation}
    S(t) = \frac{\langle \mathbf{v}(t), \mathbf{q} \rangle}{\|\mathbf{v}(t)\|_2 \|\mathbf{q}\|_2}, \quad t \in \{1, \dots, T\}.
    \label{eq:cosine_sim}
\end{equation}

\paragraph{Video-Adaptive $Z$-Score Normalization.} Global similarity cutoffs fail because baseline similarity shifts across video domains, lighting conditions, and camera motions. To isolate semantic peaks from background baselines, we compute video-level $Z$-score normalization:
\begin{equation}
    Z(t) = \frac{S(t) - \mu_S}{\sigma_S + \epsilon}, \quad \text{where } \mu_S = \frac{1}{T}\sum_{t=1}^T S(t), \quad \sigma_S = \sqrt{\frac{1}{T}\sum_{t=1}^T \big(S(t) - \mu_S\big)^2},
    \label{eq:z_score}
\end{equation}
with numerical stability constant $\epsilon = 10^{-6}$. The resulting timeline $Z(t)$ standardizes saliency scores across heterogeneous video distributions, enabling consistent peak and energy thresholding independent of domain baseline shifts.

\subsection{Stage 2: Candidate Proposal Extraction and Scoring}
\label{sec:stage2}

\paragraph{Dual-Threshold Search.} Single-threshold filtering faces a trade-off: high thresholds fragment extended actions into disjoint segments, while low thresholds introduce spurious background detections. We use a dual-threshold search with trigger threshold $\tau_{\text{high}} = 0.80$ and expansion threshold $\tau_{\text{low}} = 0.25$. An action candidate $c = [a, b]$ is initiated only if it contains a peak $Z(t_p) \ge \tau_{\text{high}}$, and is grown bidirectionally until the score falls below $\tau_{\text{low}}$.

\paragraph{Proposal Scoring via Average Saliency Energy.} To score candidate proposals without length bias, we compute the average excess similarity energy $\bar{J}(a, b)$:
\begin{equation}
    \bar{J}(a, b) = \frac{1}{b - a + 1} \sum_{t=a}^{b} \max\big(0, \, Z(t) - \tau_{\text{base}}\big),
    \label{eq:excess_energy}
\end{equation}
where baseline offset $\tau_{\text{base}} = 0.30$. Each candidate $c = [a, b]$ is assigned a composite saliency score:
\begin{equation}
    \mathrm{Score}(c) = \max_{t \in [a, b]} Z(t) + \alpha_{\text{energy}} \cdot \bar{J}(a, b),
    \label{eq:composite_score}
\end{equation}
with $\alpha_{\text{energy}} = 0.50$. Applying 1D Non-Maximum Suppression (NMS) with threshold $\theta_{\text{nms}} = 0.30$ removes redundant overlapping proposals.

\subsection{Stage 3: Duration-Adaptive Window Planning}
\label{sec:stage3}

\paragraph{Adaptive Margin and Clustering Gap.} Fixed temporal windows do not scale well across diverse video durations, over-expanding short clips and truncating long videos. We introduce duration-adaptive geometry governed by sub-linear functions:
\begin{equation}
    \Delta(T) = \mathrm{clamp}(3.5 \ln T, \, 8.0, \, 22.0)\,\mathrm{s}, \quad G(T) = \max(15.0, \, 3.5\sqrt{T})\,\mathrm{s},
    \label{eq:adaptive_geometry}
\end{equation}
where $\Delta(T)$ denotes the context margin and $G(T)$ is the clustering gap. The margin $\Delta(T)$ provides an $8.0\,\mathrm{s}$ context buffer for $30\,\mathrm{s}$ clips while expanding to $22.0\,\mathrm{s}$ for long videos. Adjacent proposals separated by distance $\le G(T)$ are clustered into candidate windows.

\paragraph{Continuous Window Merging.} Action comprehension degrades when instances from the same video are split into disjoint prompts. For candidate envelope $W_{\text{start}} = \max\big(0, \, \min_i (a_i - \Delta(T))\big)$ and $W_{\text{end}} = \min\big(T, \, \max_i (b_i + \Delta(T))\big)$ clamped to video boundaries $[0, T]$, we merge intervals into a single continuous window if the envelope span ratio satisfies:
\begin{equation}
    \frac{W_{\text{end}} - W_{\text{start}}}{T} \ge \rho = 0.70, \quad \text{or adjacent gap } \le G(T).
    \label{eq:soft_merge}
\end{equation}
This merge rule preserves contextual continuity across proximate actions while removing uninformative background frames outside the candidate envelope. The parameter $\rho$ controls the trade-off between prompt continuity and background pruning, which we analyze in $\S$\ref{sec:exp_ablations}.

\subsection{Stage 4: Dense Grounding and Structured Multi-Span Decoding}
\label{sec:stage4}

\paragraph{Budgeted Window Frame Allocation.} Within the candidate window $[W_{\text{start}}, W_{\text{end}}]$, we allocate a fixed frame budget $B \in \{64, 128, 256\}$. Sampling $B$ frames inside the candidate window yields an effective local frame rate of $\mathrm{FPS}_{\text{local}} = B / (W_{\text{end}} - W_{\text{start}})$, which concentrates visual resolution on the candidate region compared to uniform whole-video sampling.

\paragraph{Schema-Delimited Multi-Span Prompting.} Unstructured prompts often cause generation issues. We format the inference query into a structured JSON prompt:
\begin{center}
\fbox{\parbox{0.92\textwidth}{\raggedright\small\ttfamily
Given the query: "\{query\}", return ALL time spans (in seconds) where the query is relevant. Output format MUST be a JSON array of [start, end] pairs: [[s1, e1], [s2, e2], ...].
}}
\end{center}
The primary grounder $\mathcal{M}_{\text{ground}}$ (TimeLens-8B~\cite{timelens2024}) decodes exact boundary timestamps $\mathcal{Y} = \{[s_k, e_k]\}_{k=1}^M$ over the densely sampled candidate window. When candidate proposals form widely separated clusters ($\frac{W_{\text{end}} - W_{\text{start}}}{T} < \rho$), disjoint windows are prompted independently with frame budget $B$, and their resulting predicted JSON timestamp lists are concatenated and chronologically sorted.
